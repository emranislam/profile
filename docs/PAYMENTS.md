# স্বয়ংক্রিয় আনলক (bKash এসএমএস দিয়ে যাচাই)

শিক্ষার্থী Send Money করে সাইটে **Transaction ID** আর **যে নম্বর থেকে টাকা পাঠিয়েছে** সেটা দিলে, সাইট
আপনার ফোনে আসা bKash এসএমএসের সাথে মিলিয়ে দেখে। মিললে তখনই লেকচার বা কোর্স খুলে যায় আর আপনাকে
জানিয়ে দেয়। পেমেন্ট না মিললে কোনোভাবেই লিংক পাওয়া যায় না, কারণ পেইড লিংক সাইটের কোডে বা
পাবলিক তথ্যে থাকে না, শুধু যাচাইয়ের পর সার্ভার থেকে আসে।

```
শিক্ষার্থী Send Money → আপনার ফোনে bKash এসএমএস → ফোনের অ্যাপ → Apps Script → Sheet (payments)
শিক্ষার্থী সাইটে ID + নম্বর → Apps Script মিলিয়ে দেখে → মিললে লিংক + আপনার কাছে নোটিফিকেশন
```

## কী যাচাই হয়
- Transaction ID টা আপনার ফোনের এসএমএসে এসেছে কিনা
- শিক্ষার্থীর দেওয়া নম্বর প্রেরকের নম্বরের সাথে মেলে কিনা (অন্যের ID দিয়ে খোলা যায় না)
- টাকা আনলকের দামের সমান বা বেশি কিনা (৳৩০ লেকচার, কোর্সের নিজের দাম)
- আগে ব্যবহার হয়েছে কিনা (একটা ID একটাই আনলকে)
- বারবার ভুল চেষ্টা করলে এক ঘণ্টার জন্য আটকে যায়

একই শিক্ষার্থী একই ID আর নম্বর দিয়ে অন্য ফোনে বা ব্রাউজার মুছে ফেললে আনলক ফিরে পায়।

## একবারের সেটআপ

### ১. নতুন স্ক্রিপ্ট বসান
1. Google Sheet এর **Extensions → Apps Script** এ যান।
2. পুরনো কোড মুছে [`admin-apps-script.gs`](admin-apps-script.gs) এর পুরো লেখা পেস্ট করে Save করুন।
3. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**। লিংক আগের মতোই থাকবে।
4. Google নতুন অনুমতি চাইবে (বাইরের সার্ভারে যোগাযোগ, ইমেইল পাঠানো)। **Allow** দিন।

### ২. গোপন কোড ঠিক করুন
**Project Settings (⚙️) → Script Properties** এ যোগ করুন:

| Property | Value |
|---|---|
| `SMS_SECRET` | একটা লম্বা এলোমেলো কোড (যেমন `k8Xq2mZp7RvT4nLw9cYb`)। এটা কাউকে বলবেন না। |
| `TELEGRAM_BOT_TOKEN` | (ঐচ্ছিক) নিচে দেখুন |
| `TELEGRAM_CHAT_ID` | (ঐচ্ছিক) নিচে দেখুন |

Telegram না দিলে প্রতিটা আনলকে আপনার Google অ্যাকাউন্টের ইমেইলে খবর যাবে।

### ৩. Telegram নোটিফিকেশন (ঐচ্ছিক, সাথে সাথে খবর পাওয়ার জন্য ভালো)
1. Telegram এ **@BotFather** কে খুলে `/newbot` পাঠান, নাম দিন। সে একটা **token** দেবে। সেটা `TELEGRAM_BOT_TOKEN` এ বসান।
2. আপনার নতুন বটকে খুলে যেকোনো একটা মেসেজ (যেমন "hi") পাঠান।
3. ব্রাউজারে খুলুন: `https://api.telegram.org/bot<TOKEN>/getUpdates` (`<TOKEN>` এর জায়গায় আপনার token)।
4. লেখার মধ্যে `"chat":{"id":123456789` খুঁজে ওই সংখ্যাটা `TELEGRAM_CHAT_ID` এ বসান।

### ৪. ফোনে এসএমএস ফরওয়ার্ডার অ্যাপ
যে ফোনে bKash এর টাকা পাওয়ার এসএমএস আসে সেখানে একটা Android "SMS to URL / webhook forwarder" অ্যাপ বসাতে হবে।

> **সাবধান:** এই অ্যাপ আপনার সব এসএমএস পড়ার অনুমতি চায়। শুধু এমন অ্যাপ নিন যার কোড খোলা (open source) আর যেটা
> আপনি বিশ্বাস করেন। অনুমতি শুধু এসএমএস পড়া আর ইন্টারনেটের জন্য দেবেন। ওটিপি বা অন্য মেসেজ আমাদের স্ক্রিপ্ট
> রাখে না, শুধু "টাকা পেয়েছেন" ধরনের bKash মেসেজই জমা হয়।

অ্যাপে এই সেটিং দিন (অ্যাপভেদে নাম একটু আলাদা হতে পারে):
- **URL:** `আপনার-exec-লিংক?action=sms&secret=আপনার-SMS_SECRET`
- **Method:** POST
- **প্রেরক ফিল্টার:** শুধু `bKash` থেকে আসা মেসেজ
- **Body (JSON):** প্রেরকের নাম `from` আর মেসেজ `text` নামে পাঠাতে হবে। স্ক্রিপ্ট `from / sender / address / number` আর `text / message / body / content` নামগুলো চেনে।
- ফোনে ব্যাটারি অপটিমাইজেশন থেকে অ্যাপটাকে বাদ দিন, নইলে ব্যাকগ্রাউন্ডে বন্ধ হয়ে যেতে পারে।

স্ক্রিপ্ট bKash এর এই ধরনের মেসেজ পড়ে (আসল মেসেজ দিয়ে মিলিয়ে দেখা হয়েছে):
`You have received Tk 1,500.00 from 01XXXXXXXXX. Fee Tk 0.00. Balance Tk X,XXX.XX. TrxID XXXXXXXXXX at 13/10/2026 17:59`

**পরীক্ষায় পেমেন্ট না এলে:** অ্যাপে মেসেজের প্রেরক হিসেবে কী নাম দেখাচ্ছে দেখুন। স্ক্রিপ্ট শুধু নামে `bKash` (ছোট-বড় হাতের অক্ষর যা-ই হোক) থাকা মেসেজ নেয়। অন্য নাম বা নম্বর দেখালে আমাকে জানান।
অ্যাপ "error" দেখালেও Admin এর পেমেন্ট ট্যাবে মেসেজ এসে থাকলে ঠিক আছে, কারণ Google কখনো উত্তর পাঠানোর সময় আলাদা পথে ঘুরিয়ে দেয়।

### ৫. দাম সিঙ্ক
Admin এ একবার লগইন করলেই সাইটের দাম (৳৩০ লেকচার, কোর্সের দাম) আপনাআপনি স্ক্রিপ্টে চলে যায়। দাম বদলালে
সাইটের কোডে বদলে আবার Admin এ লগইন করুন।

### ৬. পরীক্ষা
1. কাউকে দিয়ে আপনার নম্বরে ৳৩০ Send Money করান।
2. Admin → **💳 পেমেন্ট** এ কয়েক সেকেন্ডে পেমেন্টটা "অব্যবহৃত" হিসেবে আসা উচিত।
3. সাইটে কোনো পেইড লেকচারে (যেমন লেকচার ২) Unlock চেপে ID আর তার নম্বর দিন। খুলে গেলে আর Telegram/ইমেইলে খবর এলে সব ঠিক।

## প্রতিদিনের কাজ
- **💳 পেমেন্ট ট্যাবে** সব পেমেন্ট দেখুন: কে কত দিল, কোনটা আনলক হয়েছে।
- সপ্তাহে একবার bKash অ্যাপের স্টেটমেন্টের সাথে এই তালিকা মিলিয়ে নিন। এটা জরুরি, কারণ এসএমএস নকল করা সম্ভব (নিচে দেখুন)।
- **এসএমএস না এলে** (ফোন বন্ধ ছিল): পেমেন্ট ট্যাবে "হাতে পেমেন্ট যোগ করুন" এ ID, টাকা আর প্রেরকের নম্বর দিন। এরপর শিক্ষার্থী নিজেই আনলক করতে পারবে।
- **"যাচাই দরকার" পেমেন্ট:** এসএমএসের ভাষা পড়া যায়নি, মেসেজটা সেখানে দেখা যাবে। ID, টাকা আর নম্বর হাতে ঠিক করে দিন, আর আমাকে ওই মেসেজের নমুনা (নম্বরের বেশিরভাগ ঢেকে) পাঠান, আমি স্ক্রিপ্ট ঠিক করে দেব।
- **ভুল বা সন্দেহজনক পেমেন্ট:** "বাতিল" চাপুন। যে আনলক হয়েছিল সেটাও বন্ধ হয়ে যাবে।
- কেউ ভুল কোর্স বা লেকচার বেছে টাকা পাঠালে ওটা আনলক হয়ে গেলে ফেরানো যায় না। প্রয়োজনে বাতিল করে সঠিকটার জন্য হাতে পেমেন্ট যোগ করুন।

## সীমাবদ্ধতা
- **ফোন চালু আর ইন্টারনেট থাকতে হবে।** না থাকলে শিক্ষার্থী "পেমেন্ট এখনো পাওয়া যায়নি" দেখে। কিছুক্ষণ পরে আবার চেষ্টা করতে বলে, দরকারে WhatsApp এ জানাতে বলে।
- **নকল এসএমএসের ঝুঁকি:** কেউ ইচ্ছা করে নকল "bKash" মেসেজ আপনার ফোনে পাঠালে ভুয়া পেমেন্ট ঢুকতে পারে। তাই bKash স্টেটমেন্ট মেলানো দরকার। আমরা শুধু প্রেরকের নামে "bKash" থাকলেই মেসেজ নিই।
- **bKash মেসেজের ভাষা বদলালে** স্ক্রিপ্টে ঠিক করতে হবে।
- **লিংক ফরওয়ার্ড:** আনলকের পর শিক্ষার্থী YouTube বা Drive লিংক অন্যকে দিতে পারে। এটা ঠেকাতে লগইন আর সুরক্ষিত ভিডিও হোস্টিং লাগবে।
- **bKash এর নিয়ম:** ব্যক্তিগত অ্যাকাউন্টের এসএমএস অ্যাপ দিয়ে স্বয়ংক্রিয় পড়া তাদের নিয়মে চলে কিনা আমরা যাচাই করিনি। bKash এ জিজ্ঞেস করে নিন।
- bKash এর Payment Gateway (API) পেলে এই এসএমএসের অংশ বাদ দিয়ে একই আনলক ব্যবস্থায় gateway জুড়ে দেওয়া যাবে।
